# Kahol Labs Website
Static responsive website for Kahol Labs featuring ViewBoost.

## Firebase Hosting
1. Install/open Firebase CLI on a computer or supported terminal.
2. Run `firebase login`.
3. In this folder run `firebase init hosting`.
4. Select the Firebase project and use the current folder as the public directory.
5. Deploy with `firebase deploy`.

Do not share Firebase passwords or private service-account keys in chat.
